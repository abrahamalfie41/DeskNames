# DeskNames
A native macOS menu bar app for naming, finding, switching, and managing desktops.

## Build and usage

See the [project documentation](outputs/DeskNames/README.md) for features, setup, and keyboard shortcuts.

On an Apple Silicon Mac with Apple's Command Line Tools installed, run:

```sh
./outputs/DeskNames/build.sh
```

The build creates `outputs/DeskNames.app` and `outputs/DeskNames.zip`. Drag the app to Applications, launch it, and grant Accessibility access when prompted.
